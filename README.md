# Симулятор худшего соседа — стартовый проект

Это минимальная структура React + Vite, собранная вокруг исходного игрового компонента и PNG/JPG-материалов.

## Запуск локально

1. Установите Node.js LTS (если ещё не установлен).
2. Распакуйте архив.
3. Откройте терминал в папке `doomer_train`.
4. Выполните:

   ```bash
   npm install
   npm run dev
   ```

5. Откройте локальный адрес, который покажет Vite (обычно `http://localhost:5173`).

Для production-сборки: `npm run build`; папка результата — `dist/`.

## Структура

- `src/App.tsx` — игровая логика и экраны из исходного прототипа.
- `src/main.tsx` — вход React-приложения.
- `src/styles.css` — Tailwind и оформление пиксельной сцены.
- `src/assets/` — предоставленные изображения; прозрачные спрайты персонажей дополнительно обрезаны по прозрачным краям в `player.png` и `baba-zina.png`.

## Важно

Это стартовая интеграция, а не финальная полировка. Сначала проверьте `npm install` и запуск. Если Vite выдаст ошибку, пришлите полный текст ошибки из терминала. Игровая логика сохранена из исходного `code_artifact.tsx`; новая сцена добавлена в экран поездки. Сейчас сцену с Бабой Зиной видно независимо от выбранного соседа — при переходе к другим персонажам потребуется переключать спрайты или показывать универсальные силуэты.
